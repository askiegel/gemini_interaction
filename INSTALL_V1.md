# Install Mini Pupper Cognitive Platform v1.0.0

Copy the release ZIP to `~/robot_services/`, then run the complete terminal block supplied with the release. The installer backs up the current cognitive directory, preserves the local `.env`, installs the Version 1.0 source, recreates the virtual environment if necessary, installs dependencies, and runs static verification.

Live robot services are not automatically started by the installer. Start them only after reviewing the configuration and placing the robot in a safe test area.
